# /ui — spaceship shell (Phase C-2)

Phone-first cockpit. `npm run ui` → http://localhost:3000 (binds 0.0.0.0 and
honors `PORT`, so Replit's webview picks it up).

- One glowing verdict at center: COILED → "WATCHING — NO TRADE",
  RETREAT → "STANDING DOWN" with the cause in plain words.
- The five coins orbit as planets; tap one for a detail card fed only by the
  tape's current-book files — if the tape is not LIVE, the card says
  UNAVAILABLE. No number is ever rendered that wasn't read from disk.
- Posture is temperature: cool blues at rest, amber bleeding in for STALKING,
  a hot flash on STRIKE, warm DIGESTING, grey drained RETREAT.
- Lock ring: +5/+8/+11 daily thresholds as ticks, filling with paper P&L.
- Thin outer arc: progress through the ET session day.
- The serpent coils the verdict ring; Ophiuchus hides in the brightest stars.
- `≋ MOTION` button and `prefers-reduced-motion` calm all animation.
- **Demo mode** (`?demo=1` or triple-tap the verdict): staged tour of all five
  postures behind an unmistakable DEMO ribbon. Demo writes nothing, reads no
  ledger, and shows dashes — never fabricated numbers styled as real data.
  Exiting returns to true state instantly. Isolation is unit-tested.

Nothing in this directory may originate trading decisions. Display only.
