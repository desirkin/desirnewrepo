# Sensor runtime configuration — 2026-09-12

These are collection extensions to the existing PAPER app. The authoritative account, trading thresholds, fees, live-order prohibition, official-primary registry, and existing decision inputs are unchanged. Configuration names are in `.env.paper.example`; real keys and approval records belong in the host's private environment. A profile REQUEST requests a gated integration; it does not grant a provider entitlement or prove successful collection.

## Current social view

The PAPER profile derives `RUMOR2_SOCIAL_CURRENT_ENABLED`, `RUMOR2_SOCIAL_REDDIT_ENABLED`, `RUMOR2_SOCIAL_STOCKTWITS_ENABLED`, `RUMOR2_SOCIAL_FACEBOOK_ENABLED`, and `RUMOR2_SOCIAL_INSTAGRAM_ENABLED` from its existing social rows. `rumor2/collector.js` creates `createSocialCurrentRuntime` under the existing journal writer fence. Each request reservation is durably acknowledged before dispatch. Facebook and Instagram share the `META_PUBLIC` allowance; Reddit OAuth token requests count too. A lost acknowledgement retries the same reservation identity.

Reddit uses application-only OAuth, then the approved subreddit `/new` listings. StockTwits uses the licensed Message Firestream with Basic authentication and opaque `seq_id`. It opens bounded five-second sample windows, not a claim of continuous full-feed coverage. Facebook uses approved Page Public Content Access and explicitly listed page IDs. Instagram uses reviewed hashtag discovery with previously resolved hashtag IDs and an authorized professional-account ID. An owner-account-only API does not substitute for either public-content route. The Meta Graph version is explicit, not guessed. Verify the account-wide seven-day hashtag cap before setting its review field.

These four sources deliver a current owner view: at most 500 records, RAM only, five-minute expiry, erased on stop, writer-fence loss or credential revocation. Reddit removals and StockTwits destroy messages erase matching content immediately. No raw post content or identities enter the permanent journal or model/research inputs. That journal records only anonymous per-provider request counts. This is limited sampled collection, not a historical archive. Senses reads `GET /api/social/current`, which requires the existing owner-unlocked session and returns `Cache-Control: no-store`. The UI refreshes this view while open. YouTube's existing metadata reader also contributes recent items; no second YouTube poller is started.

## Farcaster

`createFarcasterRuntime` polls Neynar `/v2/farcaster/cast/search/` with approved JSON-array queries, explicit daily request cap and `NEYNAR_API_KEY`. The current implementation accepts the existing FREE-plan access record and approved `SEARCH_POLLING` acquisition, with `DERIVED_FEATURES` permission. It does not enroll or assume a paid plan. Every call is reserved in the existing journal before dispatch. Its observations settle through the existing Social reconciler and research reader. Pagination advances only after settlement; restart repeats the bounded search and deduplicates against durable history. Coverage is explicitly sampled search, not firehose coverage.

## Tally

The PAPER profile enables `configOverlay.governance.enabled` and leaves `snapshotEnabled` false. Provide `TALLY_API_KEY` plus actual verified mappings in `configOverlay.governance.verifiedMappings`. A mapping has `provider: "TALLY"`, a verified `governorId` in the form `eip155:<chain>:0x<40 hex digits>`, `symbol` (a verified asset symbol or `null`), `scope: "TOKEN_GOVERNANCE"`, `verified: true`, and a positive integer `mappingVersion`. No actual governor/asset mapping is supplied by this repair.

The existing governance hourly cap and spacing apply independently to Tally. `fetchTallyProposalsPage` uses documented GraphQL proposal filters and cursor pagination, then refreshes tracked proposals even after they leave the recent page window. `normalizeTallyProposal` preserves large integer IDs, vote counts and quorum exactly as decimal strings. Indexed proposal/execution states, source clocks and receipt/knowledge clocks remain distinct. The existing governance source journal, checkpoint recovery and Memory adapter deliver the observations; none grants trading authority. Senses includes Tally's current gate and coverage.

## Publisher, infrastructure and video observations

`startPress`, `startInfra`, and `startVideo` are started by `fly.js` with contained startup failures. Their readers validate bounded source-log tails. Appends and checkpoints fsync; restart reconstructs deduplication from the source log, so a crash between append and checkpoint cannot duplicate a logical record. Corrupt or torn source history withholds collection rather than inventing history. These file-backed paths require a preserved `COBRA_DATA_DIR` and one collector process per data directory; they are not replicated databases or a cross-host leader-election system. Local files alone do not prove survival of a Replit republish. Confirm durable storage before enabling quota-bearing video collection in production.

Publishers provide feed headlines, summaries and links only, preserving direct publisher identity and Google News transport identity separately. Linked article bodies are never fetched. Reuters and Bloomberg remain `LICENSED_INTERFACE_REQUIRED`: their actual licensed interface and payload contract are missing. CNBC, FT and Google News remain profile OFF pending the existing route/terms checks; their RSS clients are implemented and fixture-tested. Remaining public feed terms and live access must be assessed on the actual host.

Cloudflare requires a Radar token and explicit ASN/prefix scope, or `INFRA_CLOUDFLARE_GLOBAL=true` when global measurement is intended. Invalid supplied scope cannot silently broaden collection. RIPE validates actual IP/CIDR/ASN ranges and samples routing status for configured resources; it is not a full RIS Live stream. NOAA records observed Kp and current storm scales separately; forecast entries are excluded and the source stays experimental.

YouTube is metadata only. The explicit daily search allowance is reserved to its checkpoint before each request, including failed calls; statistics calls are counted separately. Accounting days follow America/Los_Angeles. Opaque page tokens and query rotation survive restart; clocks advance only after the complete admitted page. An invalid checkpoint cannot reset quota. The cache prunes metadata older than 30 days during active polling; host retention/cleanup must also cover periods when the service is stopped. This is not a transcript collector or an assertion of unlimited historical retention.
